# Mobile Arcade Studio — Support

This public repository is the support and issue tracker for **Perfect Laser Cut** and **Car Sort Factory**. It contains **no Unity game source code**.

## Get help / Destek al

Use **[New issue](https://github.com/mh2jj4gn6n-droid/mobile-arcade-studio-support/issues/new/choose)** to submit a bug report or feedback. Please include the game name, app version, device, and steps to reproduce.

**Privacy warning / Gizlilik uyarısı:** GitHub issues are public. Do **not** post passwords, emails, phone numbers, purchase receipts, private photos, recovery codes, or other sensitive information. Github login is needed to submit an issue.

## Game status

Both titles are pre-release development projects. They have not been approved or publicly released on the App Store / Google Play yet.

## Privacy pages

Privacy policies and additional help information will be available on the Mobile Arcade Studio public site once it is deployed.

## Responsible use

Please be respectful when requesting support. We may remove private data accidentally posted in public issues when we become aware of it, but cannot guarantee full removal from downstream copies.
