# Mobile Arcade Studio — Support

Public support and issue tracker for **Perfect Laser Cut** and **Car Sort Factory**. This repository contains **no Unity game source code** and no production credentials.

## Official information site / Bilgi sitesi

[Mobile Arcade Studio](https://mh2jj4gn6n-droid.github.io/mobile-arcade-studio-site/) — pre-release game descriptions, bilingual privacy policies and support information.

## Submit a request / Destek bildirimi

**[Open a new issue / Yeni destek talebi](https://github.com/mh2jj4gn6n-droid/mobile-arcade-studio-support/issues/new/choose)** to report a bug or suggest an improvement. Include the game, app version, device and steps.

**Public privacy warning / Gizlilik:** All GitHub issues can be seen by everyone. Do **not** post passwords, private photos, phone numbers, email addresses, billing details, recovery codes or sensitive personal information.
